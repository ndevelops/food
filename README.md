## 🛠️ Quick Edits

- 🔄 **Change an image or video:** replace the file in `assets/` and keep the same name.
- ☎️ **Change a number:** search `index.html` for the number and update the text, `tel:` link and `wa.me` link together.
- 🥢 **Edit the Veg Starters card:** search `Starter : Veg` in `index.html`.
- 🎨 **Change colours:** edit `--gold` at the top of the `<style>` block.

---

## 🚀 Deploy (Netlify)

1. Open your site in Netlify and go to **Deploys**.
2. Drag the whole project folder (with `index.html` and `assets/`) onto the page.
3. Done. ✅
